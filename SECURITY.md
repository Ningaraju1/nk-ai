## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do not disclose it publicly.

Instead, please send an email to **[Your Email/Security Contact Placeholder]** or use the GitHub security advisory feature to report it privately.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress in resolving it. Once the vulnerability is resolved, we will publish a security advisory and credit you for the discovery.
